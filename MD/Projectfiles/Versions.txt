## Installation Commands

### Frontend

```bash
# Create Next.js app (if starting from scratch)
npx create-next-app@latest p2p-file-share --typescript --tailwind --eslint --app --no-src-dir --import-alias "@/*"

cd p2p-file-share

# Install dependencies with exact versions
npm install next@14.2.18 react@18.3.1 react-dom@18.3.1
npm install zustand@5.0.2 framer-motion@11.15.0 gsap@3.12.5 qrcode.react@3.1.0 lucide-react@0.469.0 js-file-download@0.4.12 class-variance-authority@0.7.1 clsx@2.1.1 tailwind-merge@2.6.0

# Install dev dependencies
npm install -D @types/node@22.10.2 @types/react@18.3.12 @types/react-dom@18.3.1
npm install -D eslint@8.57.1 eslint-config-next@14.2.18 prettier@3.4.2 tailwindcss@3.4.17 postcss@8.4.49 autoprefixer@10.4.20
npm install -D vitest@2.1.8 @testing-library/react@16.1.0 @testing-library/jest-dom@6.6.3 @vitejs/plugin-react@4.3.4 jsdom@25.0.1 @vitest/coverage-v8@2.1.8
```

### Signaling Server

```bash
mkdir server && cd server
npm init -y

# Install dependencies
npm install ws@8.18.0 @upstash/redis@1.34.0

# Install dev dependencies
npm install -D @types/ws@8.5.13 @types/node@22.10.2 typescript@5.6.3 tsx@4.19.2
npm install -D eslint@8.57.1 @typescript-eslint/eslint-plugin@8.13.5 @typescript-eslint/parser@8.13.5
```

## Update Policy

| Dependency Type | Update Frequency | Method |
|-----------------|------------------|--------|
| Production dependencies | Monthly | `npm outdated` → `npm update` |
| Dev dependencies | Monthly | `npm outdated -D` → `npm update -D` |
| Security patches | Immediately | `npm audit fix` |
| Major versions | Quarterly review | Test in feature branch before merging |

**Rule:** Never update all dependencies at once. Update one major version at a time and test thoroughly.
